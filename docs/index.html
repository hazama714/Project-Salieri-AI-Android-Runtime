Product

Local AI inference inside a Unity Android application.

The runtime is designed for Unity projects that need local language-model execution on Android hardware. It keeps inference close to the application and reduces dependence on network-hosted inference services.

01

Run compatible GGUF language models directly on supported Android devices.

Typical workflow

From Unity project to Android device.

Model files are supplied separately. Actual compatibility, speed, and memory use depend on the selected model, device, available memory, and project configuration.

  1. 1Import and configure the runtime in a Unity project.
  2. 2Set the local model path and runtime parameters.
  3. 3Build the Unity application for a supported Android arm64 device.
  4. 4Load the compatible GGUF model on the device.
  5. 5Run inference locally from the Unity application.

Technical repository

Source and architecture reference.

The public repository contains Android/Unity runtime architecture material, source code, diagrams, and development references. It is not intended to be a complete clone-and-run copy of the commercial package: external runtimes, models, third-party assets, and some environment-specific files are intentionally excluded.
