Runtime for Unity

Unityアプリ内で、対応するローカルGGUFモデルをAndroid端末上で実行するためのRuntime。

Unity C#からNative C++ Runtimeへ直接接続し、別途推論サーバーを用意せずに、 対応Android端末上でローカル言語モデルを実行するためのUnity向けRuntime統合です。

A Unity runtime integration for running compatible local GGUF language models directly on supported Android devices. Unity C# connects to a native C++ runtime without requiring a separate inference server.

製品 / Product

Unity Androidアプリの中でローカルAI推論を動かす。

Run local AI inference inside a Unity Android application.

Android端末上でローカル言語モデルを実行したいUnityプロジェクト向けのRuntimeです。 推論処理をアプリケーションの近くに置き、ネットワーク上の推論サービスへの依存を減らすことを目的としています。

The runtime is designed for Unity projects that need local language-model execution on Android hardware. It keeps inference close to the application and reduces dependence on network-hosted inference services.

導入の流れ / Typical workflow

UnityプロジェクトからAndroid実機へ。

From Unity project to Android device.

モデルファイルは別途用意します。実際の互換性、速度、メモリ使用量は、使用するモデル、端末、 利用可能メモリ、プロジェクト設定によって異なります。

Model files are supplied separately. Actual compatibility, speed, and memory use depend on the selected model, device, available memory, and project configuration.

  1. 1
    UnityプロジェクトへRuntimeを導入・設定する。Import and configure the runtime in a Unity project.
  2. 2
    ローカルモデルのパスとRuntimeパラメータを設定する。Set the local model path and runtime parameters.
  3. 3
    対応Android arm64端末向けにUnityアプリをビルドする。Build the Unity application for a supported Android arm64 device.
  4. 4
    対応GGUFモデルを端末上で読み込む。Load the compatible GGUF model on the device.
  5. 5
    Unityアプリからローカル推論を実行する。Run inference locally from the Unity application.
